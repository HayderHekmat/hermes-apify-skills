## Apify Token And Input Handling

- Store the Apify API token as `APIFY_TOKEN` in Hermes Agent or the host agent's secret store.
- Pass validated user input directly as the JSON body for `https://api.apify.com/v2/acts/solutionssmart~fast-google-map-scraper/runs`.
- For quick tests, POST to `https://api.apify.com/v2/acts/solutionssmart~fast-google-map-scraper/run-sync-get-dataset-items` and return the dataset items response.
- For larger jobs, POST to `https://api.apify.com/v2/acts/solutionssmart~fast-google-map-scraper/runs`, wait for completion, then fetch `https://api.apify.com/v2/datasets/{defaultDatasetId}/items?format=json&clean=true` with the returned `defaultDatasetId`.
- Do not print or store the raw `APIFY_TOKEN` in conversation logs.
